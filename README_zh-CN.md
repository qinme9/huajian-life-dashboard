## 功能亮点

### 今日总览
- 待办完成度
- 习惯打卡
- 最近纪念日倒计时
- 本月预算使用
- 人生最新一次

### 待办事项
- 新增、编辑、删除待办
- 类型筛选：学习 / 自媒体 / 杂事
- 分栏：今日 / 未来 7 天 / 已逾期 / 已完成
- 完成后自动为最近的重要日期准备进度 +10%

### 习惯打卡
- 新增、暂停、恢复、打卡
- 自动统计连续天数与总次数
- 断签后从 1 天重新开始

### 重要日期
- 支持生日、纪念日、节日、其他
- 倒计时 Hero 卡展示
- 准备进度按钮每次 +10%
- 重复规则：
  - 不重复
  - 每天
  - 每周
  - 每月
  - 每年
  - 自定义间隔（每 N 天 / 周 / 月 / 年）

### 生活费账本
- 收入 / 支出记录
- 消费分类与支付方式
- 自动归类：说明填写“食堂午餐”会自动归为餐饮
- 月预算设置：已使用百分比、剩余天数、日均可用

### 人生第一次
- 记录第一次事件、分类、日期与一句话描述

## 使用说明

- 直接打开 `index.html` 即可使用
- 也可以部署到 GitHub Pages 在线使用
- 数据保存在浏览器 `localStorage` 中
- 侧边栏支持左侧 / 右侧切换，并可通过拖动调整宽度
