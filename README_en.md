## Features

### Today Overview
- Todo completion rate
- Habit check-in status
- Next special day countdown
- Monthly budget usage
- Most recent first-time experience

### Todos
- Add, edit, and delete todos
- Filter by type: Study / Content Creation / Misc
- Columns: Today / Next 7 Days / Overdue / Completed
- Completing a task automatically adds +10% preparation progress to the nearest important date

### Habit Tracking
- Add, pause, resume, and check in
- Automatic streak and total check-in count
- Streak resets to 1 after a missed day

### Important Dates
- Birthdays, anniversaries, festivals, and others
- Countdown hero card
- Preparation progress button (+10% per click)
- Repeat rules:
  - No repeat
  - Daily
  - Weekly
  - Monthly
  - Yearly
  - Custom interval (every N days / weeks / months / years)

### Expense Ledger
- Income and expense records
- Spending categories and payment methods
- Auto categorization: entering “食堂午餐” (canteen lunch) categorizes it as Dining
- Monthly budget settings: used percentage, days left, daily available amount

### First-time Experiences
- Record first-time events, categories, dates, and a one-line memory

## Usage

- Open `index.html` directly
- Or deploy it to GitHub Pages for online use
- Data is stored in the browser `localStorage`
- The sidebar can be placed on the left or right and resized by dragging
