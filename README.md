# 花笺 · 大学生活手记

一个温暖治愈的大学生生活工作台，单文件 HTML，无需安装与构建，打开即用。

## 功能
- 今日总览：待办完成度 / 习惯打卡 / 纪念日倒计时 / 预算使用 / 人生第一次
- 待办事项：分类筛选、四类时间分栏、完成后自动关联纪念日准备进度 +10%
- 习惯打卡：自动统计连续天数与总次数
- 重要日期：支持不重复 / 每天 / 每周 / 每月 / 每年 / 自定义间隔重复
- 生活费账本：月预算、自动归类（如“食堂午餐”自动归为餐饮）
- 人生第一次：收藏值得纪念的第一次

## 使用
直接打开 `index.html`，或部署到 GitHub Pages 在线使用。
