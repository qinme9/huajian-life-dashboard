# 花笺 · 大学生活手记 / Huajian · College Life Dashboard

一个温暖治愈的大学生生活工作台，采用单文件 HTML 实现，无需安装与构建，打开即用。
A warm and healing college-life dashboard as a single HTML file. No installation or build required — open and use it directly.

🌐 **Online Demo / 在线体验**: https://qinme9.github.io/huajian-life-dashboard/

---

## ✨ Features / 功能亮点

### 今日总览 / Today Overview
- 待办完成度 / Todo completion
- 习惯打卡 / Habit check-in status
- 最近纪念日倒计时 / Next special day countdown
- 本月预算使用 / Monthly budget usage
- 人生最新一次 / Most recent first-time experience

### 待办事项 / Todos
- 新增、编辑、删除 / Add, edit, delete
- 类型筛选（学习 / 自媒体 / 杂事）/ Filter by type (Study / Content Creation / Misc)
- 今日 / 未来 7 天 / 已逾期 / 已完成分栏 / Today / Next 7 days / Overdue / Completed
- 完成后自动为最近的重要日期准备进度 +10% / Completing a task adds +10% preparation progress to the nearest important date

### 习惯打卡 / Habit Tracking
- 新增、暂停、恢复、打卡 / Add, pause, resume, check in
- 自动统计连续天数与总次数 / Automatic streak and total check-in count
- 断签后从 1 天重新开始 / Streak resets to 1 after a missed day

### 重要日期 / Important Dates
- 生日、纪念日、节日、其他 / Birthdays, anniversaries, festivals, others
- 倒计时 Hero 卡 / Countdown hero card
- 准备进度按钮每次 +10% / Preparation progress button +10% each click
- 重复规则支持 / Repeat rules:
  - 不重复 / No repeat
  - 每天 / Daily
  - 每周 / Weekly
  - 每月 / Monthly
  - 每年 / Yearly
  - 自定义间隔（每 N 天 / 周 / 月 / 年）/ Custom interval (every N days / weeks / months / years)

### 生活费账本 / Expense Ledger
- 收入 / 支出记录 / Income / expense records
- 消费分类与支付方式 / Spending categories and payment methods
- 自动归类：说明填写“食堂午餐”会自动归为餐饮 / Auto categorization: entering “食堂午餐” categorizes it as Dining
- 月预算设置 / Monthly budget settings
- 已使用百分比、剩余天数、日均可用 / Used percentage, days left, daily available amount

### 人生第一次 / First-time Experiences
- 记录第一次事件、分类、日期与一句话描述 / Record first-time events, category, date, and a one-line memory

---

## 🚀 Usage / 使用方法

- 直接打开 `index.html` / Open `index.html` directly
- 或部署到 GitHub Pages 在线使用 / Or deploy to GitHub Pages for online use
- 数据保存在浏览器 `localStorage` 中 / Data is stored in the browser `localStorage`
- 侧边栏支持左侧 / 右侧切换，并可通过拖动调整宽度 / The sidebar can be placed on the left or right and resized by dragging
